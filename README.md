# WikiShack's MediaWiki Configuration
WikiShack is a wiki farm that provides free MediaWiki hosting. WikiShack is powered by volunteers only, and we believe our code should be open source.

This repository contains our production MediaWiki configuration. Contributions (see below) are always welcome.

The WikiShack code is available under the MIT license. Portions of the code are based off of [miraheze/mw-config](https://github.com/miraheze/mw-config).
